# docuchat-evidence
RAG app that answers questions over PDFs with citations (file name and page number). Demo mode over 20-40 arXiv papers, or upload up to 5 PDFs (4 MB each). FastAPI, Pinecone, all-MiniLM-L6-v2 embeddings, Vercel. Includes a RAG vs no-retrieval baseline comparison and separate retrieval and answer metrics.
